ทะเบียนโครงการสำนักดิจิทัลการแพทย์

จัดการสถานะ 6 ขั้นตอน บันทึกวันที่รับเรื่อง ประชุมพิจารณา เสนอเซ็น ลงนาม และส่งคืนหน่วยงาน

วันประชุม:
เลขทะเบียนรับ / ปีงบฯ ชื่อโครงการ / ประเภทงบฯ & เกณฑ์ วันที่รับเรื่อง สถานะปัจจุบัน (6 ขั้นตอน) & วันประชุม วันที่สำคัญ (เสนอเซ็น/ลงนาม/ส่งคืน) จัดการ

ไม่พบข้อมูลโครงการที่ตรงกับเงื่อนไขการค้นหา

ประวัติการดำเนินงานย้อนหลัง (Audit Log)

บันทึกทุกการเปลี่ยนแปลงสถานะ วันที่เสนอเซ็น วันที่ลงนาม วันที่ส่งคืน และเหตุผลการยกเลิก

จัดการข้อมูลบน Cloud และการส่งออกรายงาน

ระบบออนไลน์บน Cloud ซิงค์อัตโนมัติระหว่างผู้ใช้งานทุกคนทันที สามารถส่งออกไฟล์ Excel หรือสำรองฐานข้อมูลเป็น JSON ได้ตลอดเวลา

ส่งออกรายงาน Excel (.CSV)

ส่งออกทะเบียนโครงการทั้งหมด พร้อมประเภทงบประมาณ ประเภทโครงการ สถานะ 6 ขั้นตอน วันที่รับเรื่อง วันที่ประชุมพิจารณา วันที่เสนอเซ็น วันที่ลงนาม และวันที่ส่งคืน เข้ารหัส UTF-8 BOM

สำรองฐานข้อมูล Cloud (JSON Backup)

ดาวน์โหลดข้อมูลโครงการทั้งหมดจาก Cloud เก็บไว้เป็นไฟล์สำรองส่วนตัวในเครื่องคอมพิวเตอร์เพื่อความปลอดภัยสูงสุด (เฉพาะ Admin)

จัดการบัญชีผู้ใช้งานระบบ (Multi-User Management)

เพิ่ม แก้ไข หรือลบบัญชีสำหรับเจ้าหน้าที่แต่ละคน ข้อมูลบัญชีซิงค์ผ่าน Cloud อัตโนมัติเพื่อให้เข้าใช้งานพร้อมกันได้หลายเครื่อง
